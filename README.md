# Project Description
StudyBuddy is a centralized web platform designed to provide students with easy access to all essential university information in one place. The system streamlines daily academic life by organizing key resources into an intuitive, role-based interface.

# The platform features:

# Dashboard (Main Page)
Displays latest university news and provides quick navigation links to all major sections of the system.

# Course Schedule & Details
Interactive schedule where each course entry can be clicked to reveal a detailed view including:

Course description

Credit hours

Prerequisites

Lecturer information

Grade or attendance statistics

# Campus Buffets Directory
A list of university canteens / buffets; selecting a buffet shows its current menu.

# Personal Area
Student-specific information such as profile details, personalized settings, and meal preferences or dietary notes.
